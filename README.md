# Rota Esplanada

De onde vem cada programa e benefício federal desde a redemocratização (1985–2026): quem criou, quem ampliou e quem só trocou o nome. Cada item traz a lei, o documento oficial ou a reportagem de onde saiu.

Parte da série [Rotas](https://fcarvalhodev.github.io/rotas/).

Site estático, sem build. Publicado pelo GitHub Pages a partir da branch `main`.
